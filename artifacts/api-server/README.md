# بوت تكت Discord

يعمل البوت مع خادم المشروع ويقرأ التوكن من سر Replit باسم `DISCORD_BOT_TOKEN`.
لا تضع التوكن في الملفات أو الرسائل أو سجلات التشغيل.

## الإعداد

1. من Discord Developer Portal افتح التطبيق الذي تريد تشغيله، ثم من صفحة **Bot** فعّل **Message Content Intent**. هذا مطلوب حتى يستقبل البوت الأمر `-help`.
2. أضف البوت إلى السيرفر من **OAuth2 → URL Generator** باستخدام نطاق `bot` والصلاحيات التالية:
   - Manage Channels
   - View Channels
   - Send Messages
   - Read Message History
   - Embed Links
   - Attach Files
3. شغّل سيرفر Replit. عند اتصال البوت تظهر رسالة `Discord bot connected` في سجل API Server.
4. داخل السيرفر اكتب `-help` واختر **تنصيب نظام التكت**، ثم أدخل ID الروم النصي. يمكن إضافة ID دور الدعم؛ اتركه فارغًا إذا لم ترد تعيين دور.

## الاستخدام

- `-help`: قائمة إعدادات البوت.
- **خيارات التكت**: إضافة وحذف فئات التكت. تبقى فئة واحدة على الأقل.
- **مظهر البوت**: مالك تطبيق البوت فقط يمكنه تغيير الاسم والصورة وحالة النشاط من القائمة.
- **Bio**: لا يمكن تغييره من Bot API؛ غيّره يدويًا في Developer Portal.
- لوحة التكت تنشئ قناة خاصة بصاحب الطلب والبوت، مع دور الدعم الاختياري. يقدر صاحب التكت وفريق الدعم إغلاقه، بينما زر استدعاء صاحبه متاح لفريق الدعم والمشرفين.

الإعدادات وسجلات التذاكر محفوظة في ملف بيانات محلي تحت `.data/`، وهو مستثنى من Git.
